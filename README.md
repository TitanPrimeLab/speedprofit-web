# speedprofitai.com

Web corporativa de SpeedProfit AI — React + Vite + Tailwind, desplegada en
Cloudflare Pages.

## Arranque rápido

```bash
npm install
npm run dev
```

## Antes de nada

1. Coloca las imágenes en `public/img/` (`fondo.png`, `logo.png`, `og-image.png`)
2. Pega los textos legales reales en `src/paginas/Privacidad.jsx` y `Terminos.jsx`
3. Lee `CLAUDE.md` — contiene las reglas del proyecto y las decisiones pendientes

Todo el contenido textual está centralizado en `src/contenido.js`.
